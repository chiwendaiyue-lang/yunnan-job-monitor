# 需求规格说明书（摘要）

本文档对应《云南省企业就业失业数据采集系统》工作说明书，以下为结构化摘要，详细字段与流程以工作说明书为准。

## 1. 用户角色

- **企业用户**：维护备案信息、按期填报、查询本企业历史数据、修改密码、浏览通知。  
- **市用户**：审核辖区内企业上报数据、发布通知、修改密码。  
- **省用户**：企业备案审核与查询、报表审核与汇总上报、数据修改（留痕）、删除/退回、汇总与导出、多维与图表分析、通知管理、系统管理（上报时限、用户、角色、监控）。

## 2. 企业功能

| 模块 | 要点 |
|------|------|
| 备案信息 | 地区只读、组织机构代码≤9位字母数字、两级企业性质与行业、联系方式与地址校验等 |
| 数据填报 | 建档期/调查期就业人数；若调查期小于建档期，须填减少类型与主要原因等 |
| 数据查询 | 仅本企业、可浏览不可导出 |

## 3. 省级功能

| 模块 | 要点 |
|------|------|
| 企业备案 | 列表、按调查期与地区查询、查看、导出 Excel |
| 报表管理 | 查看、退回（可备注）、审核通过、上报部级 |
| 数据汇总 | 按调查期汇总 |
| 数据修改 | 修正数据另存，保留原始与日志 |
| 取样/图表分析 | 地区占比饼图；两期对比与多期趋势 |
| 数据查询与导出 | 多条件查询与导出 |
| 通知 | 发布、修改、删除；企业与省可浏览 |
| 系统管理 | 调查期时限、用户、角色、系统监控 |

## 4. 市级功能

数据审核、通知发布、修改密码（与省级审核链路衔接）。

## 5. 非功能

安全认证、操作留痕、符合国家系统数据交换预留接口。
