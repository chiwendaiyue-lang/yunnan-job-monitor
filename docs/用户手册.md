# 用户手册（简版）

## 登录

使用管理员分配的账号登录。角色分为企业、市、省，登录后菜单不同。

## 企业用户

1. **企业信息**：填写或修改备案字段，保存后可提交备案（进入待审核）。  
2. **数据填报**：在开放的上报期内选择调查期，填写就业人数及相关原因，保存后提交。若调查期人数低于建档期，须完整填写减少类型与主要原因。  
3. **数据查询**：按调查期等条件查看本企业各期状态与数据（页面浏览，不提供导出）。  
4. **通知**：查看省、市发布的通知标题与正文。

## 市用户

在「审核上报」中查看待审列表，对辖区内企业提交的数据执行通过或退回（退回时可填写理由）。

## 省用户

1. **备案企业**：查看已备案企业列表，支持条件筛选与导出。  
2. **调查期**：维护各期上报开始、结束时间。  
3. **审核与退回**：对市级已通过的数据做终审或退回企业修改；退回支持备注。  
4. **数据修正**：对明显错误记录修正值，系统保留原始记录与修正说明。  
5. **通知**：新增、编辑、删除通知。  
6. **用户管理**：维护账号与角色（演示环境已预置测试账号）。

## 常见问题

- **无法填报**：当前不在上报期内，或上期数据被退回需先修改再提交。  
- **无法删除用户**：该用户已有上报数据时禁止删除（与工作说明书一致）。
